## How to do X (runbook)

- **Add an agent role:** create `agents/<role>.py` (module docstring + `LOG = config.getLogger('<role>')`), wire it from `orchestrator.py`, add `tests/test_<role>.py`, then `python tools/repo_map.py`.
- **Add a config flag:** add an `ALL_CAPS` constant in `config.py` sourced from `.env` via `os.getenv`/`_envBool`/`_envPath`; reference as `config.NAME`.
- **Add a Discord embed:** add a builder in `notifications/discord_bot.py` (see existing `*Embed` builders) + send via `discord.sendEmbed`.
- **Add + run one test:** use `tests/factories.py` builders; run `python tools/dev.py check tests/test_<x>.py`.
