# Localhost Web Dashboard Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Redesign the localhost web dashboard (`notifications/webdash_page.py`, served at `http://localhost:8787`) to top-tier UI/UX quality — accessibility, safety/feedback, motion, responsiveness, visual polish — with zero new dependencies and zero backend/contract changes.

**Architecture:** Split the current 168-line single `PAGE` HTML string into a `notifications/webdash_page.py` facade plus three sibling modules (`webdash_styles.py`, `webdash_markup.py`, `webdash_script.py`), following the repo's existing "module → sub-modules + re-export facade" pattern (see `discord_*.py`). `webdash.py` and its tests are untouched — they only ever see the final assembled `PAGE` string. Because there is no JS test runner in this repo, "tests" for this feature are: (a) a byte-identical golden snapshot before any visual change, (b) the existing `tests/test_bloomberg_webdash.py` assertions (must keep passing unmodified — they check literal substrings survive), (c) a new structural test asserting the DOM `id="..."` hooks the JS depends on are present, and (d) a manual browser smoke check with Chrome DevTools MCP at the end.

**Tech Stack:** Python stdlib only (`http.server`), hand-written HTML/CSS/JS (no framework, no CDN, no build step). Test runner: `pytest`.

**Design doc:** `docs/superpowers/specs/2026-07-01-webdash-redesign-design.md` — read it once before Task 1.

```js
const DESTRUCTIVE=new Set(['abort','reject']);
function toast(msg,ok){
  const box=document.getElementById('toasts');
  const t=document.createElement('div');
  t.className='toast '+(ok?'ok':'fail');
  t.textContent=msg;
  box.appendChild(t);
  requestAnimationFrame(()=>t.classList.add('show'));
  setTimeout(()=>{t.classList.remove('show');setTimeout(()=>t.remove(),300);},4000);
}
function confirmModal(msg){
  return new Promise(resolve=>{
    const root=document.getElementById('modalRoot');
    root.innerHTML='<div class="modal-scrim"><div class="modal" role="alertdialog" aria-modal="true">'
      +'<div>'+esc(msg)+'</div><div class="row2">'
      +'<button class="btn" id="mCancel">Cancel</button>'
      +'<button class="btn danger" id="mOk">Confirm</button></div></div></div>';
    document.getElementById('mOk').onclick=()=>{root.innerHTML='';resolve(true)};
    document.getElementById('mCancel').onclick=()=>{root.innerHTML='';resolve(false)};
  });
}
async function ctl(action,arg,btn){
  if(DESTRUCTIVE.has(action)){
    const ok=await confirmModal('Are you sure you want to '+action+' this run? This cannot be undone.');
    if(!ok)return;
  }
  if(btn)btn.classList.add('busy');
  try{
    const res=await fetch('/api/control',{method:'POST',headers:{'content-type':'application/json','x-9to5-token':__T},body:JSON.stringify({action,arg})});
    if(!res.ok)throw new Error('HTTP '+res.status);
    toast(action+' sent',true);
  }catch(e){
    toast(action+' failed: '+e.message,false);
  }finally{
    if(btn)btn.classList.remove('busy');
  }
}
```
