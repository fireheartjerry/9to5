### Merge recipe (apply to each pair below)

For each merge:
1. Read both source files fully.
2. Write the destination file: combined module docstring describing both, then all `from __future__ import annotations`, then a deduplicated import block (union of both files' imports, no duplicates), then all test classes/functions from file A, then all from file B.
3. `git rm` both source files.
4. `git add` the destination file.
5. Run `pytest <destination_file> -q` to verify the merged file passes in isolation before moving to the next merge.

Watch for: duplicate class names between the two source files. If both define e.g. `class TestFoo`, rename the second to `class TestFooB` to avoid silent shadowing.

- [ ] **Step 1: Exempt tests/ from size_audit.py**

Open `tools/size_audit.py`. Find `_tracked_py_files()`:

```python
def _tracked_py_files() -> list[Path]:
    paths: list[Path] = []
    for line in _run_git_ls():
        p = REPO_ROOT / line
        parts = set(p.relative_to(REPO_ROOT).parts)
        if parts & {"logs", "venv", "__pycache__", ".pytest_cache"}:
            continue
        paths.append(p)
    return paths
```

Change the exclusion set to:

