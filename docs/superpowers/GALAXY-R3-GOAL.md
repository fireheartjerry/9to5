# GALAXY R3 — Program Goal

Set 2026-07-28. This is a direction and priority statement for the glowup. It is
not a specification, not a plan, and not activation authority.

## Mission

Convert 9TO5 from a system that *hopes* a model session succeeded into one that
**proves it** — an evidence-routed autonomous kernel where every attempt is
isolated, leased, verified, and promoted under earned authority, at **zero
incremental external cost**. This is not a feature wave. It changes what the unit
of autonomy *is*.

## The one measure that matters

**How much of the system is running and producing real evidence — and how fast
that evidence becomes live authority.**

Not tasks closed. Not specs frozen. Not tests written. A stage that is fully
implemented and emitting nothing has produced nothing.

## Near objective — close Stage 2 and LIGHT IT

**Complete Stage 2, the Transactional Attempt Kernel, and activate it through the
installed-LKG updater — the first genuinely live, authoritative component of the
glowup.**

Stage 2 is the hinge. Pulsar, Quark, and Accretion are spec-frozen with **zero
source**, all blocked behind this gate. Until it lands, nothing above it can
start.

Complete means:
- AJ15b and AJ15c closed, including the clauses currently escalated as ambiguous
  (snapshot capability replacement, broker-side absence re-proof, the manifest
  clause's true target). Those need an operator/reviewer decision, not more code.
- AJ15e green: the full AJ10–AJ15 dual-runtime matrix, every deterministic
  failure retained as a fixture.
- AJ16 registry retirement; AJ17 retained-root TOCTOU closure.
- Kernel Task 3 + Task 4 landed as one atomic source wave, then Task 5 review and
  the installed-LKG controller activation.
- Every claim verified on **both Python lanes plus real POSIX/WSL**, each packet
  carrying corrected independent specification and code-quality review.
- The pre-existing controller-state failure triaged, not inherited.

Exit condition: canonical `main` is never the staging area; every retry is its own
prepare → verify → promote transaction; promotion happens only through a fenced,
crash-reconcilable receipt — **and the controller is live, not merely built.**

## Horizon objective — Stage 7, Accretion

The stage that changes what this system *can be*. Accretion inverts the premise of
every long-horizon agent: the context window stops being memory and becomes a
**disposable cache compiled from immutable, causally closed external state**.

Hard pins, acceptance conditions, revocations, and verifier failures survive
**arbitrarily long runs** — no truncation, no silent forgetting. When a packet
cannot be satisfied the system raises `ContextUnsatisfiable` instead of quietly
dropping the constraint that mattered. Twenty-two tasks: append-only ledger,
Merkle-authenticated history, exact and Pareto packet selection,
publish-before-evict compaction — every accelerator proven against a permanent
exact oracle before it earns a single byte of authority.

This is what makes true long-horizon autonomy structural rather than aspirational.

## The ladder between

Stage 3 durable commands and effects → Stage 4 Lensing Fabric (Claude and Codex as
*peer* drivers, neither subordinate) → Stage 5 Pulsar, one deterministic
scheduling spine replacing every fragmented queue → Stage 6 Quark, proof-carrying
solver primitives → **Stage 7 Accretion** → Stages 8–11: Supernova trials,
qualified topology overlays, Orrery projections, and finally GraphWarrant-gated
admission of the full **131-node / 250-edge** topology under a benchmark campaign
that must be passed, not asserted.

## Standing constraints

Zero paid APIs, metered inference, or recurring SaaS — local Claude Code, Codex,
and Ollama only.

**Nothing stays dark.** The ladder is dark → shadow → qualified → live. Dark
produces *zero* evidence; you cannot earn live from dark, only from running.
Every component that lands goes to shadow promptly and starts emitting real
receipts against real work. Dark is a build state measured in days, not a resting
state.

**Target: light.** Each stage is judged the same way — shadow within its wave,
qualified in the wave that follows, live as soon as its receipts clear. Gates stay
real and self-promotion stays forbidden, because the purpose of the gates is to
make the light **trustworthy**, not to postpone it.

## Current position (2026-07-28)

Stages 0–1 closed with receipts. Stage 2 in progress, source-dark. Stages 3–11 not
started. **Zero of the 131 nodes is runtime-enabled.** Activation is
operator-gated by design: only the external LKG updater can activate, behind the
global launch embargo and a fresh TOFU ceremony — no agent can lift that from
inside the repository, deliberately. Going light is an operator ceremony, and the
kernel's readiness is the thing that earns it.
