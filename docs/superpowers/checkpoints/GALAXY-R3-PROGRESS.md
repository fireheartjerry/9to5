## Status language

- DONE: the task has current evidence and, where required, a stage receipt.
- IN PROGRESS: implementation or verification is actively underway.
- SOURCE-DARK: source exists or is substantially implemented, but it has no
  production influence and still needs the applicable qualification gate.
- AUDIT REQUIRED: the worktree contains relevant source, but this checkpoint
  has not re-proved the full approved task.
- PREREQUISITE: an external/runtime prerequisite is absent; unrelated safe
  source work may continue.
- PENDING: no completion claim is made.
- ACTIVE: runtime authority exists. No GALAXY overlay is ACTIVE at this
  checkpoint.

Checklist marks are reserved for finite deliverables with a durable evidence
point. Continuing prohibitions and recurring maintenance are written as
`Guardrail:` or `Recurring gate:` bullets and are never marked complete. A
checked source task does not imply qualification, eligibility, activation, or
authority.

Treat `CURRENT.md`, the detailed session checkpoint, and this ledger as one
checkpoint bundle. Update all three atomically whenever shared HEAD, stage,
authority, failure scope, protected-install state, or next-action information
changes.
