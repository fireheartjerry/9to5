# AgentScope — harvest

## 1. Repo
- **Name:** AgentScope (2.0), by `agentscope-ai` (Alibaba/Tongyi lineage; arXiv 2402.14034).
- **What it is:** Production-ready, async-first multi-agent framework whose thesis is "strict protocol, replaceable intelligence" — give increasingly-agentic LLMs clean primitives (events, permissions, sandboxed workspaces, composable middleware) rather than rigid prompt orchestration. Ships a FastAPI multi-tenant / multi-session agent service with built-in **agent teams**, **task planning**, **RAG**, and **long-term memory**.
- **Maturity:** High. 2.0 GA (2026-05), active (RAG + Agent Team + Mem0 landed 2026-06), PyPI-published, OpenTelemetry tracing, Docker/E2B sandbox backends, Qdrant vector store, web UI. Code is heavily docstringed and defensively written.
- **Primary language:** Python 3.11+ (async throughout, Pydantic models).
- **LICENSE:** Apache-2.0 (verified `LICENSE`).

## 2. Architecture sketch
- **Agent = reasoning-acting loop over `AgentState`** (`agent/_agent.py`, `state/_state.py`). State separates `summary` (compressed) from `context` (uncompressed live msgs), plus `permission_context`, `tool_context` (read-cache w/ LRU+mtime invalidation), `tasks_context`, and `middle_context` (scratch for middlewares across replies). The whole state is one serializable Pydantic object → trivially checkpointable.
- **Composable middleware** wraps the loop at six hook points: `on_reply`, `on_reasoning`, `on_acting`, `on_model_call`, `on_compress_context`, `on_system_prompt` (`middleware/_base.py`). Budget, tracing, RAG, long-term memory, TTS are all middlewares; `is_implemented()` lets the agent build per-hook chains. Clean way to layer policy without forking the loop.
- **Event stream** (`event/`): the agent yields typed events (`REPLY_START`, `MODEL_CALL_*`, `TEXT_BLOCK_*`, tool events, `RequireUserConfirm`, `RequireExternalExecution`) — one bus drives UI, HITL, and tracing.
- **Permission engine** (`permission/`): per-tool, per-mode (DEFAULT/EXPLORE/ACCEPT_EDITS/BYPASS/DONT_ASK) allow/deny/ask rule lists; matching delegated to each tool (`Bash`=cmd prefix, `Read/Write/Edit`=glob).
- **Workspace/sandbox abstraction** (`workspace/`): one interface, three backends — `LocalWorkspace`, `DockerWorkspace`, `E2BWorkspace` — providing tools, skills, MCP clients, and **offload** (persist compressed context + big tool results for later agentic retrieval).
- **RAG stack** (`rag/`): `KnowledgeBase` handle = embedding model + Qdrant collection + always-applied `metadata_filter` (multi-tenant scoping); approximate-token chunker; agentic vs static retrieval middleware.
- **Agent service / teams** (`app/`): storage-backed multi-tenant service; a leader session spawns worker agents (`TeamCreate`/`AgentCreate`/`TeamSay`) that coordinate via a message bus + inbox + wakeup triggers, with permission inheritance from leader to worker.
- **Task graph** (`state/_task.py`, `tool/_task/*`): tasks with `blocks`/`blocked_by` dependency edges + `owner`, mutated by LLM via `TaskCreate/Update/Get/List` tools — a shared, claimable to-do graph.

## 4. Top 3 takeaways
1. **Context compaction + budget governor are the two highest-ROI, lowest-friction steals.** `_compress_context_impl` (trigger/reserve-ratio split → structured summary → offload pointer → drop-oldest fallback) and `ReplyBudgetControlMiddleware` together fill 9to5 gaps 8 and 5 with self-contained, portable Python that doesn't need the rest of AgentScope. They directly lift the 7B-truncation ceiling and add the cost enforcement 9to5 only captures opportunistically.
2. **The dependency-aware task graph as incrementally-editable LLM tools is the right shape for 9to5's planning gap.** `blocks`/`blocked_by`/`owner` + `TaskCreate/Update` replace 9to5's brittle one-shot decomposition with a graph the executor refines as it learns — and the `owner` field is the seam for multi-worker coordination, addressing gaps 1 and 7 at once.
3. **AgentScope is the reference design for the three infra gaps 9to5 has barely started**: Qdrant-backed ANN RAG with metadata scoping (gap 4), the Local/Docker/E2B workspace sandbox (gap 6), and OpenTelemetry span tracing (gap 5). These are heavier ports but worth mining the interfaces from rather than designing cold.

---
**One-line summary:** AgentScope 2.0 is a mature, Apache-2.0, async multi-agent framework that cleanly nails five of 9to5's eight gaps (planning graph, compaction, RAG, sandbox, tracing) via composable middleware — a rich harvest target.

**Highest-ranked technique:** Context-compaction-with-offload (`agent/_agent.py` `_compress_context_impl`) — trigger/reserve-ratio hierarchical summarization into a structured `summary` with a disk-offload breadcrumb and drop-oldest fallback, the exact long-horizon mechanism 9to5 lacks today.
