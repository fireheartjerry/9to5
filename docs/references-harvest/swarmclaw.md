# SwarmClaw — Harvest

## 1. Repo

- **Name:** SwarmClaw (`@swarmclawai/swarmclaw`, v1.9.39).
- **What it is:** Self-hosted, single-process **multi-agent runtime + control plane** — a Next.js/TypeScript app that runs persistent autonomous agents (an "org chart" of CEO/worker agents) with durable memory, MCP tools, skills, schedules, delegation, and 23+ LLM/CLI provider backends (Claude Code, Codex, Gemini CLI, Ollama, etc.). Markets itself as a Claude Code / LangChain alternative.
- **Maturity:** High. v1.9, npm-published, Electron desktop builds, Docker/fly/railway/render deploy targets, CI, ~456 server modules each with co-located `.test.ts`, OpenTelemetry wired. Production-grade, actively versioned.
- **Primary language:** TypeScript (Node 22, Next.js, LangGraph, better-sqlite3, zod).
- **License:** **MIT** (`LICENSE`, "Copyright (c) 2026 SwarmClaw Contributors"). Clean to borrow ideas/code.

Closest peer to 9TO5: same "autonomous agent does a whole job" thesis, but built as a *long-lived multi-agent org* over swappable provider CLIs rather than 9TO5's single Ollama-brain → Claude-executor pipeline. Many of 9TO5's thin spots are first-class subsystems here.

## 2. Architecture sketch

- **Provider/CLI abstraction:** every agent runs against a pluggable provider (API or delegated CLI: `claude_code`, `codex_cli`, `gemini_cli`, `ollama`…); a **capability router** + **delegation advisory** pick the tool/sub-agent by classified task intent and scored capability match.
- **LangGraph execution core** with a custom **SQLite checkpoint saver** (`langgraph-checkpoint.ts`): per-step checkpoints + pending-writes table + parent links + time-travel deletes — durable mid-task resume baked into the graph runtime.
- **Subagent swarm layer** (`agents/subagent-swarm.ts`): parallel spawn with `allSettled`/`firstSettled`/`quorumSettled`/`cancelAll`, concurrency bucketing via per-execution locks, persisted swarm snapshots, restart-"lost" recovery.
- **Board/task graph:** tasks with `blockedBy`/`blocks` edges; DAG cycle validation + `cascadeUnblock` that auto-queues dependents and **passes upstream results forward** (lightweight blackboard).
- **Three-tier memory** (working/durable/archive) in SQLite with embeddings, **temporal decay**, **MMR diversification**, query expansion, and offline **dream-cycle** consolidation.
- **Autonomy supervisor** (`supervisor-reflection.ts`): observes each run, emits incidents, and fires auto-actions (`block`/`replan`/`compact`/`budget_trim`) folded back into run context — a closed self-correction loop.
- **Verification stack:** weighted eval scorer (contains/regex/tool_used/**llm_judge**), full agent-regression harness with SWE-bench/GAIA scenarios, and a configurable task quality gate.
- **Cross-cutting plumbing:** OpenTelemetry spans, per-agent hourly/daily/monthly **cost budgets**, 7-detector **tool-loop detection**, git-snapshot **guardian** rollback with human approval, A2A (Agent2Agent) JSON-RPC protocol + `.well-known` discovery, sandboxed Docker browser/fs bridges.

## 4. Top 3 takeaways

1. **SwarmClaw already solves 9TO5's three weakest gaps with portable code.** The LangGraph **SQLite checkpoint saver** (mid-task/step resume, gap 3), the **hierarchical context-compaction** module (gap 8), and the **7-detector tool-loop detector** (gap 5/self-correction) are each self-contained, MIT-licensed, and directly address documented 9TO5 thin spots. They are the highest ROI to study/port.

2. **Its multi-agent layer is the blueprint 9TO5 wants for gap 7.** `subagent-swarm` gives real coordination primitives (`quorumSettled`, `firstSettled`, `cancelAll`, concurrency bucketing, restart recovery), and `dag-validation.cascadeUnblock` turns task dependencies into a working scheduler that forwards `upstreamResults` to dependents — a lightweight blackboard that lets parallel workers share results instead of clobbering one tree.

3. **Verification and cost are first-class here vs. ad-hoc in 9TO5.** The weighted **LLM-judge scorer**, the **SWE-bench/GAIA agent-regression harness**, and per-agent **hourly/daily/monthly cost budgets with 80% alerts** show how to move 9TO5 from "string-present in source" verifies and opportunistic `cost_usd` to behavioral scoring + budget-threshold alerting.

---
**One-line summary:** SwarmClaw is a mature MIT multi-agent runtime over swappable provider CLIs whose checkpointing, context-compaction, swarm coordination, and verification subsystems map almost 1:1 onto 9TO5's top gaps. **Highest-ranked steal:** the **SQLite LangGraph checkpoint saver** (`src/lib/server/langgraph-checkpoint.ts`) — a transactional per-step + pending-writes journal that gives 9TO5 the mid-subtask resume durability (gap 3) it completely lacks today.
