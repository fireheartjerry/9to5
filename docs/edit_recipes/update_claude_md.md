# Update CLAUDE.md

Use when changing Claude Code operating rules.

## Read first

- `CLAUDE.md`
- `docs/DOC_MAINTENANCE.md`
- `LLM_MAP.md`

## Rules

- Keep `CLAUDE.md` short and directive.
- Do not move full architecture lore into `CLAUDE.md`.
- Link to deeper docs instead.
- Update related docs if rules change.

## Good CLAUDE.md content

- behavior rules
- patch discipline
- test-selection rules
- source-of-truth rules
- forbidden paths
- final response format
- terminology such as Terminal A and Nightclaw

## Bad CLAUDE.md content

- giant file trees
- full Discord feature lore
- full Obsidian vault docs
- long architecture essays
- stale roadmap assumptions

## Verification

No code tests required unless docs tooling exists. Run docs lint/check if available.
